# ZERO-EDGE PROP MATH • can the firm's rules alone pay more than the evaluations cost?

Every trade is a fair coin for its target: wins +T R with probability 1 ÷ (1 + T), else −1 R, minus 3% of R in costs — NO edge. One trade a day (or a second after a losing first). 20,000 simulated evaluations per row, each run through evaluation → funded → payouts with the firm's rules (LUCID FLEX 50K ($120) • TRADEIFY SELECT 50K ($99, 40%, Flex cap $2,500) • TAKE PROFIT TRADER 50K ($170 + $130 PRO)).
